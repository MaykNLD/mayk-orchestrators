# Proyectos Web — mayk.dev

Esta carpeta contiene un subdirectorio por cada proyecto cliente completado o en curso.

## Estructura de cada proyecto

```
proyectos/
└── nombre-cliente-YYYY/
    ├── brief-cliente.md          ← Brief completado en Fase 0
    ├── informe-fase-1.md         ← Estrategia aprobada
    ├── informe-fase-2.md         ← Diseño y construcción aprobados
    ├── informe-fase-3.md         ← QA y entrega
    ├── checklist-entrega.md      ← Firmado por el cliente
    └── README.md                 ← Estado actual del proyecto
```

## Estados posibles

| Estado | Descripción |
|---|---|
| 🔴 EN CURSO — Fase X | Proyecto activo en la fase indicada |
| 🟡 EN REVISIÓN | Esperando aprobación del cliente o Director |
| 🟢 ENTREGADO | Proyecto cerrado y aceptado por el cliente |
| ⚫ ARCHIVADO | Proyecto pausado o cancelado |

## Nota de privacidad

Los archivos de cliente (assets, documentos privados, credenciales) **no se incluyen en este repositorio**.
Son gestionados fuera del repo y entregados al cliente de forma segura al cierre del proyecto.
